# Rudra Arts And Handicrafts

## Build
- Replace the template home screen with a premium, responsive heritage storefront and shared navigation/footer.
- Add customer views for shopping, product details, collections, gallery, business information, cart, checkout, wishlist, and account flows using History API navigation.
- Add browser-persisted mock commerce data and functional cart, wishlist, checkout, contact, and inquiry interactions.
- Add a mock-authenticated admin area for dashboard, products, categories, orders, customers, homepage/banner content, testimonials, inquiries, and settings.
- Create a cohesive token-based burgundy, ivory, charcoal, and antique-gold design system, then verify the preview and key user flows.

## Technical approach
- Keep the existing Lovable React/Vite runtime intact; author feature code in standard JavaScript/JSX without new packages or backend services.
- Implement the visible path switch and client navigation with the browser History API, with a catch-all page entry for direct visits.
- Use local mock records and localStorage persistence, inline SVG icons, CSS, and existing Tailwind styling only.
